# Kinetix: Robotics-Assisted Lower-Limb Rehabilitation Device

**Live report:** https://cde4301-kinetix.github.io/kinetix-final/

A robotic rehabilitation device for stroke patients that combines motor actuation,
real-time sensor feedback (IMUs and a load cell) and an adaptive user interface.
Final-year project for CDE4301, National University of Singapore (AY25/26).
